# Haide

Haide는 macOS용 **IDE + ADE**입니다. AI 에이전트 개발 환경(ADE)과 코드 탐색·diff·편집이 되는
통합 개발 환경(IDE)을 한 앱에 합쳤습니다. 이름도 IDE와 ADE를 합친 'aide'에서 왔습니다.

- **ADE**: 프로젝트마다 Git 워크트리를 만들고, 워크트리마다 Claude Code·Codex 에이전트를 터미널 탭으로 띄워 함께 일합니다.
- **IDE**: 에이전트가 바꾼 코드를 같은 앱에서 VS Code급 편집기로 읽고, 정의·참조로 따라가고, diff로 검토하고, 전체 검색으로 찾습니다.

주요 기능:

- 에이전트 상태(실행 중·질문·승인 필요·완료)를 사이드바와 상태바에서 확인하고, 완료·질문은 알림으로 받습니다.
- 코드 탐색(정의로 이동·참조 찾기·심볼), 변경 파일·diff 리뷰, 전체 검색·바꾸기, VS Code 단축키를 지원합니다.
- Claude·Codex 계정 사용량을 상태바에 표시합니다.
- 여러 에이전트에게 일을 나눠 주는 오케스트레이션(`haide` CLI)과 GitHub·Jira 대시보드가 들어 있습니다.
- 앱을 꺼도 터미널과 에이전트는 계속 실행되고, 다시 켜면 그대로 이어집니다.

이 저장소는 설치 파일 배포용입니다. 설치 파일은 [Releases](../../releases)에 있습니다.

## 요구 사항

- macOS 11 이상, **Apple Silicon(M1 이상)**. Intel Mac은 지원하지 않습니다.
- `git`
- 에이전트를 쓰려면 [Claude Code](https://docs.anthropic.com/en/docs/claude-code) 또는 [Codex CLI](https://github.com/openai/codex)가 설치·로그인돼 있어야 합니다.
- 선택: GitHub 대시보드는 로그인된 [`gh`](https://cli.github.com/), Jira 대시보드는 Jira API 토큰이 필요합니다.

## 설치

### 설치 명령 (권장)

터미널에 붙여넣어 실행합니다.

```sh
curl -fsSL https://raw.githubusercontent.com/kimsh8337/haide-releases/main/install.sh | bash
```

- 최신 릴리스를 받아 체크섬과 서명(Haide 인증서 지문)을 확인한 뒤 `/Applications/Haide.app`에 설치하고 실행합니다.
- 터미널로 받은 파일은 macOS의 '확인할 수 없는 개발자' 경고 없이 열립니다.
- Haide가 켜져 있으면 검증이 끝난 뒤 'Haide를 종료하고 설치할까요? [Y/n]'를 묻습니다. Enter로 종료하면 설치 후 다시 엽니다(Haide 터미널 안에서 실행해도 됩니다). 1.0.7부터는 앱의 업데이트 팝오버에서 **지금 설치**를 눌러도 됩니다.
- 스크립트 내용은 [install.sh](install.sh)에서 미리 볼 수 있습니다.
- 옵션: `HAIDE_VERSION=1.0.5`(특정 버전), `HAIDE_INSTALL_DIR=~/Applications`(`/Applications`에 쓸 수 없을 때),
  `HAIDE_NO_OPEN=1`(설치 후 실행 안 함), `HAIDE_NO_WAIT=1`(Haide가 켜져 있으면 기다리지 않고 중단), `HAIDE_QUIT=1`(묻지 않고 Haide 종료).

Homebrew 설치는 지원하지 않습니다. 예전에 Homebrew로 설치했다면 `brew uninstall --cask --force haide`로
기록을 지운 뒤 위 명령으로 설치합니다(설정 `~/.haide`는 유지됩니다).

### DMG

1. [Releases](../../releases/latest)에서 `Haide-<버전>-arm64.dmg`를 받습니다.
2. DMG를 열고 **Haide**를 **응용 프로그램(Applications)** 폴더로 끌어 놓습니다.
3. Haide는 아직 Apple 공증을 받지 않아서, 브라우저로 받은 앱은 처음 열 때 macOS가 실행을 막습니다.
   경고가 뜨면 **완료**를 누르고 **시스템 설정 → 개인정보 보호 및 보안**에서 'Haide' 항목의 **그래도 열기**를
   누릅니다. 또는 터미널에서 `xattr -dr com.apple.quarantine /Applications/Haide.app`을 실행합니다.
   **휴지통으로 이동**은 누르지 마세요(앱이 지워집니다).

### 처음 실행 후 뜨는 권한 창

- **전체 디스크 접근 안내**: 데스크탑·문서·다운로드·iCloud Drive 안의 프로젝트를 처음 열기 전에 한 번 묻습니다.
  **전체 디스크 접근 켜기**를 골라 시스템 설정에서 Haide를 켜면 폴더마다 묻는 창이 더 뜨지 않습니다
  (켠 뒤 macOS가 다시 열기를 물으면 **다시 열기**). **폴더마다 묻기**를 고르면 macOS가 폴더별로 묻습니다.
- **키체인 접근**: Claude 계정 사용량을 표시하려고 Claude Code 로그인 정보를 읽을 때 묻습니다. **항상 허용**을
  누르면 다시 묻지 않습니다. 거부해도 다른 기능은 그대로 쓸 수 있습니다.
- **알림**: 에이전트 완료·질문 알림을 받으려면 허용합니다.

Haide는 매 버전 같은 인증서로 서명합니다. 그래서 업데이트해도 위 허용이 유지됩니다(1.0.4 이하에서 처음
올라올 때만 한 번 다시 묻습니다).

## 단축키

macOS 기준입니다. **터미널에서도** 열에 ✓가 있는 단축키는 터미널에 커서가 있을 때도 앱 명령으로 동작하고,
없는 단축키는 터미널 밖(편집기·사이드바 등)에서만 동작합니다. 한글 입력 중에도 ⌘ 단축키는 그대로 동작합니다.

### 앱 전체

| 단축키 | 명령                             | 터미널에서도 |
| ------ | -------------------------------- | ------------ |
| ⇧⌘P    | 명령 팔레트 보기                 | ✓            |
| ⌘P     | 파일로 이동                      | ✓            |
| ⌘N     | 워크트리 만들기                  | ✓            |
| ⌘O     | 폴더 열기                        |              |
| ⌘B     | 사이드바 보이기/숨기기           | ✓            |
| ⌥⌘B    | 도구 패널 보이기/숨기기          |              |
| ⇧⌘E    | 파일 보기                        | ✓            |
| ⇧⌘G    | 변경 보기                        | ✓            |
| ⇧⌘F    | 전체 검색                        | ✓            |
| ⇧⌘H    | 전체 검색에서 바꾸기             | ✓            |
| ⇧⌘A    | 응답 패널 열기·닫기              | ✓            |
| ⌥⌘D    | 대시보드 열기 · GitHub/Jira 전환 | ✓            |

### 탭과 화면 분할

| 단축키          | 명령                                                  | 터미널에서도 |
| --------------- | ----------------------------------------------------- | ------------ |
| ⌘T              | 새 탭(터미널)                                         | ✓            |
| Ctrl+`          | 새 터미널                                             | ✓            |
| ⌘W              | 탭 닫기                                               | ✓            |
| Ctrl+Tab · ⇧⌘]  | 다음 탭                                               | ✓            |
| Ctrl+⇧Tab · ⇧⌘[ | 이전 탭                                               | ✓            |
| ⌘D · ⌘\         | 오른쪽으로 분할(편집기 안의 ⌘D는 다음 같은 항목 선택) | ✓            |
| ⇧⌘D · ⇧⌘\       | 아래로 분할(편집기 안의 ⇧⌘D는 분할하지 않음)          | ✓            |

### 터미널

터미널에 커서가 있을 때만 동작합니다.

| 단축키  | 동작                                                     |
| ------- | -------------------------------------------------------- |
| ⌘F      | 터미널 찾기                                              |
| ⌘C      | 선택한 글자 복사(선택이 없으면 아무것도 하지 않음)       |
| ⌘V      | 붙여넣기                                                 |
| ⌘K      | 화면 지우기                                              |
| ⇧Enter  | 줄바꿈(Claude Code·Codex 입력창에서 보내지 않고 줄 추가) |
| ⌘← / ⌘→ | 줄 처음 / 끝으로                                         |
| ⌥← / ⌥→ | 이전 / 다음 단어로                                       |
| ⌘⌫      | 커서 앞 줄 전체 지우기                                   |

### 편집기와 diff

편집기에 커서가 있을 때 동작합니다. 여기 없는 편집 단축키(찾기 ⌘F, 바꾸기 ⌥⌘F, 주석 ⌘/, 여러 커서 등)는
VS Code 기본값과 같습니다.

| 단축키       | 명령                                     |
| ------------ | ---------------------------------------- |
| ⌘S           | 파일 저장                                |
| ⌘L           | 에이전트에게 보내기                      |
| ⌘D           | 다음 같은 항목도 선택(VS Code와 같음)    |
| ⇧⌥F          | 문서 서식                                |
| ⌘K ⌘F        | 선택 영역 서식                           |
| F12          | 정의로 이동                              |
| ⌘F12         | 구현으로 이동                            |
| ⇧F12         | 참조 찾기                                |
| ⌥F12         | 정의 미리보기                            |
| ⇧⌘O          | 파일 안 심볼로 이동                      |
| F2           | 이름 바꾸기                              |
| ⌘.           | 빠른 수정(에이전트에게 고치게 하기 포함) |
| Ctrl+- / ⌃⇧- | 뒤로 / 앞으로 이동                       |
| ⌥F5 / ⇧⌥F5   | 다음 / 이전 변경으로 이동(diff 포함)     |

### 검색 패널과 응답 패널

| 단축키          | 명령                               | 어디서              |
| --------------- | ---------------------------------- | ------------------- |
| ⌥⌘C / ⌥⌘W / ⌥⌘R | 대소문자 구분 / 단어 단위 / 정규식 | 검색어 입력칸       |
| ⌥⌘Enter         | 모두 바꾸기                        | 검색 패널 열림      |
| F4 / ⇧F4        | 다음 / 이전 검색 결과              | 검색 패널 열림      |
| ⌘Enter          | 답 보내기                          | 응답 패널 질문 카드 |

### macOS 기본

⌘Q 종료, ⌘H 가리기, ⌥⌘H 다른 앱 가리기, ⌘M 최소화, ⌘Z / ⇧⌘Z 실행 취소 / 다시 실행, ⌘X·⌘C·⌘V·⌘A 편집.

### 단축키가 없는 명령

명령 팔레트(⇧⌘P)에서 실행합니다: 그룹 닫기, 도구 패널 보기, 도구 패널을 왼쪽으로/오른쪽으로,
에이전트 실행, 터미널 지우기, 터미널 선택 복사, Haide 종료 및 모든 세션 종료, 다음 질문·완료
에이전트로 이동, 프로젝트 신뢰 관리, 파일 열기, 설정 파일 열기, 현재 줄 문제를 에이전트에게 보내기,
다음/이전 변경 파일, 인라인 diff 켜기/끄기, 변경 되돌리기, 선택한 범위 스테이지, 디스크 파일과 비교,
커밋 그래프 보기, 모든 브랜치 보기 전환, 작업 현황 열기, 로드맵 열기, Jira: 연결 설정.

## 업데이트

앱이 새 버전을 확인합니다(시작할 때, 실행 중 6시간마다, 잠자기에서 깨어날 때). 새 버전이 있으면 상태바 오른쪽에
**업데이트**가 표시되고, 누르면 설치 명령을 복사할 수 있습니다. 끄려면 설정 파일에 `"update.check": false`를 넣습니다.

- 위 설치 명령을 다시 실행합니다. Haide 터미널 안에서 실행해도 됩니다. Haide가 켜져 있으면 종료(⌘Q)할 때까지
  기다렸다가 설치하고 다시 엽니다. 설정과 실행 중인 에이전트 세션은 유지됩니다.
- DMG로 업데이트하면 macOS가 다시 경고할 수 있습니다. 위 'DMG' 절대로 허용하세요.

## 데이터와 삭제

- 설정과 기록은 `~/.haide` 폴더에 저장됩니다.
- 지우려면 **Haide 메뉴 → Haide 종료 및 모든 세션 종료**로 끈 뒤 `/Applications/Haide.app`을 휴지통에 버립니다.
  설정까지 지우려면 `~/.haide` 폴더도 지웁니다.
